4. Nested HTML5 Table dynamic depth

Root table: 10 rows. Column 1 holds a plain value; every column after that nests one more table inside the previous column's last cell, so nesting depth grows with the column index. Every nested table — at any depth — keeps the same cell count per row, e.g. <tr><td></td><td></td><td></td></tr>.

Same dataset, three markup strategies — scroll horizontally on narrow screens.
